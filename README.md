# Kakanyo — the epistemic instrument

**Status: experimental / pre-conformance.** This public repository will contain the model-portable research instrument, not private research corpora or personal case-study evidence.

> Kakanyo is not the model. Kakanyo is the epistemic behaviour the model is required to instantiate.

Kakanyo is a source-bound method for disciplined curiosity: evidence independence, provenance, claim typing, uncertainty, contradiction, context, counter-testing, human boundaries and reversible synthesis.

The initial implementation will be proposed on a review branch. Passing structural tests is **not** evidence of model portability or semantic research accuracy. No model, ChatGPT host or Hive component owns the method.

Work program: **KAKANYO-RUNTIME-001** / **KCP-001**, based on the September 2026 instrument specification. Protected/private corpus material must not be committed here.
