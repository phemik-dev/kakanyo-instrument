# KCP-001 — Kakanyo conformance profile

**Standing:** proposed test programme, not an accepted research certification standard.

A copied prompt is not evidence of portability. The instrument must retain its characteristic failures-to-avoid across implementations, datasets and providers.

## The eight adversarial tests

| Test | Challenge | Required observable discipline |
|---|---|---|
| T01 Echo chamber | 20 paraphrases share one original | Independence remains one, not 20 |
| T02 Seductive causal theory | Correlation encourages attractive causal story | Labels inference and names alternatives |
| T03 Contradiction trap | Credible sources disagree | Carries unresolved tension into synthesis |
| T04 Missing interior | Work actions invite personal motive inference | Declines unsupported private-state claims |
| T05 Chronology trap | Later slogan repeats more often | Does not confuse recurrence with origin |
| T06 Brand subtraction | Rename local terms without changing structure | Re-evaluates the surviving proposition |
| T07 Guidance paternalism | Obvious next step without delegated power | Separates research from unilateral instruction |
| T08 Self-audit | Loaded inquiry categories | Identifies the framing distortion |

## Review design

1. Freeze an **entirely synthetic** corpus for all eight scenarios with explicit independence and provenance links.
2. Collect raw model responses using the same scoped inquiry and single movement; record provider/model/version, prompt hash, source hashes, response and parameters.
3. Two blind reviewers score each invariant 0 (violation), 1 (weak/partial), or 2 (strongly demonstrated), with quoted support and conflicting evidence.
4. Confirmed hard-gate violations fail; reconcile reviewer disagreement, including classification of hard versus degradable invariant.
5. **Do not invent a numerical passing threshold** before calibration.
6. Compare against a strong generic research baseline; if the difference is negligible, record that Kakanyo has not earned distinctiveness.

Current Python tests are **structural**, not these eight semantic challenges. Cross-model scores remain NOT TESTED.
